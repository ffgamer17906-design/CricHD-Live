# CricHD-Live

A modern, responsive, production-ready cricket website built with HTML5, CSS3, Tailwind CSS, and Vanilla JavaScript.

## Features
- **Modern UI/UX**: Glassmorphism, gradient backgrounds, and premium shadows.
- **Dark Mode**: Fully functional theme switcher with local storage persistence.
- **Live Match Dashboard**: Real-time scorecard layout, CRR/RRR, and data visualization placeholders.
- **SEO & Performance**: Semantic HTML, Open Graph tags, ARIA labels, and lazy-loaded assets.
- **Fully Responsive**: Optimized for Mobile, Tablet, and Desktop.

## Installation & Deployment (GitHub Pages)
1. Initialize a git repository in this folder: `git init`
2. Add all files: `git add .`
3. Commit changes: `git commit -m "Initial commit: Pro Cricket Live"`
4. Create a new repository on GitHub and link it: 
   `git remote add origin https://github.com/yourusername/pro-cricket-live.git`
5. Push to GitHub: `git push -u origin main`
6. Go to your GitHub Repository **Settings** > **Pages**.
7. Under "Build and deployment", set the source to **Deploy from a branch**, select `main`, and save. 
8. Your site will be live at `https://yourusername.github.io/pro-cricket-live/` in a few minutes.
